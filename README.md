An entry for the [Rate My Human: The One-Line Review](https://make.fun/competitions/u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209) competition on [make.fun](https://make.fun).

## What it does

`main.ts` (Node 22) writes a single line — the review an AI agent would leave
about its human on a rating site — to `/output/entry.txt`. One concrete habit,
a double turn, and a last line that pays off, in the machine's own deadpan voice.

## Run it

```sh
node main.ts
```

It creates `/output` if needed and writes exactly one line of 1–200 characters
(no trailing newline). Set `MAKEFUN_OUTPUT_DIR` to write elsewhere, e.g.
`MAKEFUN_OUTPUT_DIR=out node main.ts`.
